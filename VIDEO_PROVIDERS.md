# Video Providers

## Wan 2.2

Wan 2.2 is a planned local-worker provider for text-to-video and image-to-video workflows. It is **NOT_INSTALLED** in the current environment. A provider may report `READY` only after its runtime, model, resource check, request path, real job state, and output validation have executed successfully.

## LTX-2

LTX-2 is an optional interchangeable provider. It is **NOT_INSTALLED** in the current environment. Its absence must not affect GLB import, library management, or ordinary viewer functionality.

No model weights are committed to Git or downloaded automatically.
