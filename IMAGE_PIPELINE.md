# Image Pipeline

The planned local image pipeline is text/image input → selected installed provider → real output validation → asset storage. The contract supports text-to-image, image-to-image, editing, inpainting, outpainting, backgrounds, upscaling, dimensions, seed, and model selection.

No image model or ComfyUI image workflow is installed in the current environment. Image generation therefore remains `NOT_INSTALLED`; no image-generation UI or fake output is enabled.
